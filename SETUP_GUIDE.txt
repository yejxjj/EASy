================================================================
  Fides — AI Washing Detection  /  실행 가이드
================================================================

■ 프로젝트 구조
  AI-ESA/
  ├── server.py          ← FastAPI 백엔드 (포트 8000)
  ├── frontend/          ← Next.js 프론트엔드 (포트 3000)
  └── SETUP_GUIDE.txt    ← 이 파일

================================================================
  1. 사전 준비
================================================================

  [Python]
  - Python 3.10 이상 필요
  - 설치 확인: python --version

  [Node.js / pnpm]
  - Node.js 18 이상 필요
  - pnpm 설치: npm install -g pnpm
  - 설치 확인: node --version / pnpm --version

  [DB]
  - AWS RDS MySQL 사용 (별도 설정 불필요)
  - 인터넷 연결 필요

================================================================
  2. 백엔드 실행
================================================================

  ① 패키지 설치 (최초 1회)
  --------------------------------------------------
  pip install fastapi uvicorn sqlalchemy pymysql
              python-jose bcrypt pydantic

  또는 한 번에:
  pip install "fastapi[all]" sqlalchemy pymysql python-jose bcrypt

  ② 서버 실행
  --------------------------------------------------
  cd C:\AI-ESA
  python server.py

  → http://localhost:8000 에서 실행됨
  → 터미널에 "Uvicorn running on http://0.0.0.0:8000" 표시되면 정상

================================================================
  3. 프론트엔드 실행
================================================================

  ① 패키지 설치 (최초 1회)
  --------------------------------------------------
  cd C:\AI-ESA\frontend
  pnpm install

  ② 개발 서버 실행
  --------------------------------------------------
  pnpm dev

  → http://localhost:3000 에서 실행됨
  → 터미널에 "Local: http://localhost:3000" 표시되면 정상

================================================================
  4. 실행 순서 (매번)
================================================================

  터미널 1 — 백엔드
  ------------------
  cd C:\AI-ESA
  python server.py

  터미널 2 — 프론트엔드
  ----------------------
  cd C:\AI-ESA\frontend
  pnpm dev

  브라우저에서 http://localhost:3000 접속

================================================================
  5. 캐시 초기화 (화면이 안 바뀔 때)
================================================================

  Windows CMD:
    rmdir /s /q C:\AI-ESA\frontend\.next
    pnpm dev

  Mac / Linux:
    rm -rf C:\AI-ESA\frontend/.next
    pnpm dev

  브라우저: Ctrl + Shift + R (강제 새로고침)

================================================================
  6. 환경변수 (선택)
================================================================

  프론트엔드 API 주소 변경이 필요한 경우:
  frontend/.env.local 파일 생성 후 아래 내용 추가:

    NEXT_PUBLIC_API_BASE_URL=http://localhost:8000

  기본값이 이미 localhost:8000 이므로 로컬 개발 시 불필요

================================================================
  7. 주요 기술 스택
================================================================

  Backend  : Python / FastAPI / SQLAlchemy / AWS RDS MySQL
  Frontend : Next.js 16 / React 19 / Tailwind CSS v4 / pnpm
  Auth     : JWT (python-jose) / bcrypt
  AI       : Ollama / Gemini / 온톨로지 기반 분석
